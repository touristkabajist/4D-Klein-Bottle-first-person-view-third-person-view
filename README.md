## Recent changes

- **Update (2026-10-19)** — Improved first-person controls and UI tweaks in `index.html`.
  - Better manual movement support with the Up/Down arrow keys when in first-person view.
  - Automatic fly-through now only advances while Auto 4D rotation is enabled; arrow keys can move the camera manually regardless of auto-rotation state.
  - Minor UI/help text and slider behavior improvements.
  - Commit: https://github.com/touristkabajist/4D-Klein-Bottle-first-person-view-third-person-view/commit/3e660f52f6c9107851cf1722faa39d00a5e54bf2

---

Open `index.html` in a modern browser to run the demo. Drag to rotate the 4D rotation planes, use the mouse wheel to zoom, and press `V` to toggle between first- and third-person views.
